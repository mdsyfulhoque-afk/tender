# Reusable actual-agent prompt contracts

These templates compile the APES methods into bounded tasks. They are reusable future instructions only when an authorized orchestrator assigns them. Source quotes and template role names do not prove an agent was launched. Replace every parameter with actual data before use; do not invent missing IDs, sources, tool names, timestamps or results.

## Product task contracts are different artifacts

`SOURCE_INSPECT`, `REQUIREMENT_CANDIDATES`, `EVIDENCE_RELEVANCE` and `CITATION_CHECK` are fixed executable SYSTEM contracts in the product. They are not these natural-language delegated-build prompts, and they cannot choose tools from PDF text. Their actual runtime receipts record real file hashes, attempts and zero model calls; product-generated UUIDs cannot impersonate external Codex platform run IDs.
